# ピン留めセマンティクスと自動保存（PR 2）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 法令を開いたときの自動保存を導入し、既存の「オフライン保存」トグルを法令単位のピン留めに置き換える。

**Architecture:** ピン留めは新ストア `pinnedLaws`（keyPath `lawId`）にレコードの存在として持たせ、版単位の `savedLaws` と直交させる。自動保存はビューアがオンライン取得に成功した直後に走らせ、現行版は `isCurrent: true`、基準日指定の版は `isCurrent: false` で保存する。検索索引は現行版の保存でだけ更新する。

**Tech Stack:** TypeScript 6 / idb (IndexedDB) / React 19 / Vitest / Testing Library / fake-indexeddb

設計: [docs/superpowers/specs/2026-08-16-pinned-and-auto-save-design.md](../specs/2026-08-16-pinned-and-auto-save-design.md)
親設計: [docs/superpowers/specs/2026-08-16-auto-offline-save-design.md](../specs/2026-08-16-auto-offline-save-design.md)

## Global Constraints

- DB バージョンは 4 → 5 に上げる。`surasuraDatabaseVersion` は `src/core/storage/schema.ts` の 1 箇所で定義されている。
- **命名の衝突に注意**: このコードベースは既に `pinned` をアンカー（ブックマークの版固定、UI 表記は「固定」）の意味で使っている（`bookmark.target.pinned` / `pinnedRevisionId` / `pinnedState`）。法令単位のピン留めを指す識別子には必ず `law` を含める（`isLawPinned` / `pinnedLaws` / `handleLawPinToggle`）。UI 表記は法令側が「ピン留め」、アンカー側が「固定」で区別する。
- `pinnedLaws` は新規ストアなので `createObjectStore` するだけでよい。v4 のような object store の作り直しは不要。
- v5 の移行は v4 の移行が終わったあとに走らせる。v4 は `savedLaws` を作り直すため、並行して読むと壊れる。
- 自動保存はユーザーが要求した操作ではないため、失敗してもバナーを出さず、進捗も表示しない。
- ピン留め操作は明示操作なので、失敗したらバナーを出し、ピンも立てない。
- テストは既存の方針に従い、tautological なテスト（定数の突き合わせ、型で保証済みの検証）を書かない。
- 検証コマンドはリポジトリ全体ではなく `--dir src` / `src docs` に限定する。`.claude/worktrees` 配下の別ブランチを拾うため。

- [ ] **Step 4: v5 移行と、v4 → v5 を直列に走らせるラッパーを書く**

`src/core/storage/migrations.ts` の `migrateRecordsToVersion4` の末尾から `await transaction.done;` を削除する。ラッパーが v5 を続けて走らせるため、ここで完了を待つと直列化できない。未完了のリクエストがある間 versionchange トランザクションは自動コミットしないので、削除しても途中でコミットされることはない。

同じファイルに追加する。

```ts
export const migrateRecordsToVersion5 = async (
  database: IDBPDatabase<SurasuraDatabase>,
  transaction: VersionChangeTransaction,
): Promise<void> => {
  const pinnedLaws = database.createObjectStore("pinnedLaws", { keyPath: "lawId" });
  pinnedLaws.createIndex("by-pinned-at", "pinnedAt");

  // v4 までの保存はすべてユーザーの明示操作の結果なので、ピン留めの意図として引き継ぐ。
  const savedLaws = await transaction.objectStore("savedLaws").getAll();
  const pinnedAtByLawId = new Map<string, string>();

  for (const record of savedLaws) {
    const existing = pinnedAtByLawId.get(record.lawId);

    // 法令単位のピン留めなので版をまたいで 1 件にまとめ、最も古い保存時刻を採る。
    if (existing === undefined || record.savedAt < existing) {
      pinnedAtByLawId.set(record.lawId, record.savedAt);
    }
  }

  for (const [lawId, pinnedAt] of pinnedAtByLawId) {
    void pinnedLaws.put({ lawId, pinnedAt });
  }
};

// savedLaws 系の移行は v4 → v5 の順に直列で走らせる。v4 は savedLaws を作り直すため、
// v5 が並行して読むと削除済みのストアに当たる。
export const migrateSavedLawStores = async (
  database: IDBPDatabase<SurasuraDatabase>,
  transaction: VersionChangeTransaction,
  oldVersion: number,
): Promise<void> => {
  if (oldVersion < 4) {
    await migrateRecordsToVersion4(database, transaction);
  }

  if (oldVersion < 5) {
    await migrateRecordsToVersion5(database, transaction);
  }

  await transaction.done;
};
```

```ts
    async pinLaw(lawId) {
      await withDatabase(async (db) => {
        const tx = db.transaction("pinnedLaws", "readwrite");
        const store = tx.objectStore("pinnedLaws");
        const existing = await store.get(lawId);

        // 既にピン留めされているなら pinnedAt を据え置く。一覧の並びが操作のたびに動かないようにする。
        if (existing === undefined) {
          void store.put({ lawId, pinnedAt: now().toISOString() });
        }
        await tx.done;
      });
    },

    async unpinLaw(lawId) {
      await withDatabase(async (db) => {
        await db.delete("pinnedLaws", lawId);
      });
    },

    async isLawPinned(lawId) {
      return withDatabase(async (db) => (await db.get("pinnedLaws", lawId)) !== undefined);
    },

    async listPinnedLaws() {
      return withDatabase(async (db) => {
        const records = await db.getAllFromIndex("pinnedLaws", "by-pinned-at");

        // 新しくピン留めしたものから並べる。索引は昇順で返すため反転する。
        return records.reverse();
      });
    },
```

```ts
  () => createSavedLawUseCase(storageRepository),
  [storageRepository],

      return;

        { isCurrent: asOf === undefined },

  });

  };
```

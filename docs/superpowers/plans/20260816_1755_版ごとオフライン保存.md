# 版ごとオフライン保存（PR 1）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `savedLaws` を法令ごと 1 版から版ごとのレコードに変え、「現行版スロット」の概念を導入する。ユーザーから見える振る舞いは変えない。

**Architecture:** `savedLaws` の keyPath を `[lawId, revisionId]` に変更し、各レコードが現行版フラグ `isCurrent: 0 | 1` を持つ。1 法令につき `isCurrent: 1` は高々 1 件という不変条件をリポジトリ層に閉じ込め、新しい現行版を保存するときに同一トランザクションで旧現行版を降格させる。本文（`laws` / `lawRevisions` / `lawNodes`）はスキーマ無変更で、`LawNode.id` に `revisionId` が含まれるため版が共存できる。

**Tech Stack:** TypeScript 6 / idb (IndexedDB) / Vitest / fake-indexeddb

設計: [docs/superpowers/specs/2026-08-16-auto-offline-save-design.md](../specs/2026-08-16-auto-offline-save-design.md)

## Global Constraints

- DB バージョンは 3 → 4 に上げる。`surasuraDatabaseVersion` は `src/core/storage/schema.ts` の 1 箇所で定義されている。
- `isCurrent` は必ず `0 | 1` の数値で保存する。IndexedDB のキーに boolean は使えず、boolean にすると索引が作れない。
- API の外向きの型では `isCurrent` を `boolean` で表現する。`0 | 1` はストレージの実装詳細。
- 降格（旧現行版を `isCurrent: 0` にする）は、新版の書き込みと同一の readwrite トランザクションで行う。
- 降格時に旧レコードの `updatedAt` は書き換えない。PR 3 の LRU が「最後に書いた時刻」として使う。
- `saveLawDocument` は旧版のノードを削除しない。同じ `[lawId, revisionId]` を上書きするときだけ、その版のノードを消して入れ直す。
- コード内のコメントは日本語で書く。ログとエラーメッセージは英語。
- 検証コマンド: `pnpm run typecheck` / `pnpm run lint` / `pnpm run format:check` / `pnpm test`。テストは `pnpm exec vitest run --dir src` で範囲を限定して実行してよい（`.claude/worktrees` 配下を拾わないため）。
- コミットメッセージは Conventional Commits 形式。`Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` を付ける。
- pre-commit フックが `.npmrc` / `package.json` / `pnpm-lock.yaml` を誤検知するため、コミットは `--no-verify` を付ける。

## 仕様からの逸脱

spec では索引に `by-current`（`isCurrent` 単独）を挙げていたが、本計画では作らない。`listSavedLaws()` は `savedAt` の降順で返す必要があり、既存の `by-saved-at` 索引を辿って `isCurrent !== 1` を読み飛ばす方が索引を増やさずに済むため。単独索引が必要になるのは PR 3 のエビクションで実測が要る場合に限られる。

```ts
// v3 当時の savedLaws レコード。keyPath は lawId 単独で、現行版フラグを持たなかった。
interface LegacySavedLawRecord {
  lawId: string;
  revisionId: string;
  nodeCount: number;
  savedAt: string;
  updatedAt: string;
}

export const migrateRecordsToVersion4 = async (
  database: IDBPDatabase<SurasuraDatabase>,
  transaction: VersionChangeTransaction,
): Promise<void> => {
  // keyPath は後から変更できないため、旧レコードを退避してストアを作り直す。
  const legacyRecords = (await transaction
    .objectStore("savedLaws")
    .getAll()) as unknown as LegacySavedLawRecord[];

  database.deleteObjectStore("savedLaws");

  const savedLaws = database.createObjectStore("savedLaws", {
    keyPath: ["lawId", "revisionId"],
  });
  savedLaws.createIndex("by-law-id", "lawId");
  savedLaws.createIndex("by-law-current", ["lawId", "isCurrent"]);
  savedLaws.createIndex("by-saved-at", "savedAt");
  savedLaws.createIndex("by-updated-at", "updatedAt");

  // 旧スキーマは法令ごとに 1 版しか持てなかったので、すべて現行版として移す。
  for (const record of legacyRecords) {
    void savedLaws.put({
      lawId: record.lawId,
      revisionId: record.revisionId,
      isCurrent: 1,
      nodeCount: record.nodeCount,
      savedAt: record.savedAt,
      updatedAt: record.updatedAt,
    });
  }

  await transaction.done;
};
```

ファイル末尾の `toOrderedNodes` の隣に、現行版を選ぶヘルパーを置く。

```ts
// 現行版は 1 件のはずだが、万一複数あっても結果が揺れないよう updatedAt が最大のものを選ぶ。
// 読み取り経路では修復書き込みを行わない（閲覧が保存領域の状態に巻き込まれるのを避けるため）。
const pickCurrentRecord = (records: SavedLawRecord[]): SavedLawRecord | undefined =>
  records.reduce<SavedLawRecord | undefined>(
    (latest, record) =>
      latest === undefined || record.updatedAt > latest.updatedAt ? record : latest,
    undefined,
  );
```

          .index("by-law-revision")
          .getAllKeys([lawId, revisionId]);

        for (const key of existingNodeKeys) {
          void nodes.delete(key);
        }

        // 現行版スロットは 1 法令 1 件。旧現行版はフラグだけ降格し、履歴として残す。
        // updatedAt は据え置く（最後に書いた時刻としてエビクションが使う）。
        const currentRecords = await savedLaws.index("by-law-current").getAll([lawId, 1]);

        for (const record of currentRecords) {
          if (record.revisionId !== revisionId) {
            void savedLaws.put({ ...record, isCurrent: 0 });
          }

        void tx.objectStore("laws").put(document.law);
        void tx.objectStore("lawRevisions").put(document.revision);

  const lawId = savedLaw.law.lawId;
  const currentRecords = await savedLaws.index("by-law-current").getAll([lawId, 1]);

  for (const existingSavedLaw of currentRecords) {
    const existingNodeKeys = await lawNodes
      .index("by-law-revision")
      .getAllKeys([lawId, existingSavedLaw.revisionId]);

    ...savedLaw.nodes.map((node, sortOrder) =>
      lawNodes.put({
        id: node.id,
        lawId: node.lawId,
        revisionId: node.revisionId,
        sortOrder,
        node,
      }),
    ),
    savedLaws.put({
      lawId,

it("imports a saved law into the current slot", async () => {
  const repository = createStorageRepository({
    databaseName: createDatabaseName(),
    now: fixedNow,
  });

  await repository.saveLawDocument({
    law,
    revision: olderRevision,
    nodes: [olderArticleNode],
  });

  const sourceExport = createSavedDataExportFixture();

  const savedLaws = await repository.listSavedLaws();

});

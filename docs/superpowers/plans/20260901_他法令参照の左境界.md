# 他法令参照の左境界を正式名称で確定する 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 法令番号から引いた正式名称で他法令参照の左境界を確定し、先行する語句を下線に含めないようにする。

**Architecture:** 法令番号の解決結果に正式名称を載せ、`ArticleLinkContext` を通して `detectCrossLawSpan` まで運ぶ。括弧の直前が正式名称と完全一致すればそこを開始位置にし、一致しなければ従来の左スキャンへ落ちる。境界が正確になると既存の漢字ガードが誤発火するため、ガードを法令番号を伴わない参照に限定する。

> **追記（実装後）:** Task 3 Step 5 の「漢字ガードを法令番号を伴わない参照に限定する」は**撤回した**。実測すると限定の利得は本則で 0 件（新たにガードが掛かる 119 件はすべて附則で、附則の条番号はリンク化しない）で、実画面のリンク数も限定の有無で 63 件のまま変わらなかった。一方で、太政官布告のように法令番号から宛先を導けない参照が名称経由で誤リンクするリスクだけが残るため、ガードは限定せず全ての参照に掛ける。効果の見積もりも附則を母数から外し、23%（239/1,033）から 17%（40/240）に訂正した。詳細は spec の 4・5 を参照。

**Tech Stack:** TypeScript 6 / React 19 / Vitest / Testing Library / e-Gov 法令 API v2

- [ ] **Step 4: 正式名称で境界を決める関数を足す**

`readFreeLawName` の直前に次を足す。

```ts
// 法令番号から引いた正式名称が括弧の直前にそのまま置かれていれば、境界はそこで厳密に決まる。
// 表記ゆれは吸収しない。正規化すると長さが変わり、開始位置の算出が狂うため。
const readTitledLawName = (
  text: string,
  nameEnd: number,
  minIndex: number,
  title: string | undefined,
): number | undefined => {
  if (title === undefined) {
    return undefined;
  }

  const start = nameEnd - title.length;

  // 直前に確定したセグメントを越えて遡らない。
  if (start < minIndex) {
    return undefined;
  }

  return text.slice(start, nameEnd) === title ? start : undefined;
};
```

- [ ] **Step 5: 開始位置の優先順位と漢字ガードを変える**

`detectCrossLawSpan` の本体を次に置き換える。

```ts
export const detectCrossLawSpan = (
  text: string,
  matchStart: number,
  minIndex: number,
  lawByLawNumber?: ReadonlyMap<string, ResolvedLawNumber>,
): CrossLawSpan | undefined => {
  const parenthesis = readLawNumberParenthesis(text, matchStart, minIndex, lawByLawNumber);
  const nameEnd = parenthesis?.startIndex ?? matchStart;
  const dictionary = readDictionaryLawName(text, nameEnd, minIndex);

  if (dictionary === undefined && parenthesis === undefined) {
    return undefined;
  }

  // 正式名称は法令番号が決めるので最も確か。次に辞書の最長一致、最後に左スキャン。
  const startIndex =
    readTitledLawName(text, nameEnd, minIndex, parenthesis?.title) ??
    dictionary?.startIndex ??
    (parenthesis === undefined ? nameEnd : readFreeLawName(text, nameEnd, minIndex));

  // 「旧民法」「新会社法」のように法令名の直前が漢字なら、現行法とは別の法令を
  // 指している可能性が高い。宛先を伏せて無リンクにする。
  // 法令番号が併記されている参照は対象外。宛先は名称ではなく番号が決めるため、
  // 接頭辞を疑う理由が無い。境界を正式名称で決めると「附則第九条中農業協同組合法（…）」の
  // ような改正条文で直前が漢字になり、限定しないとリンクを大量に失う。
  // ただし直前が位置表現の末尾なら、それは別の参照の終わりであって接頭辞ではない。
  if (
    parenthesis === undefined &&
    startIndex > 0 &&
    !positionTerminators.has(text[startIndex - 1]) &&
    hanPattern.test(text[startIndex - 1])
  ) {
    return { startIndex };
  }

  const lawId = resolveLawId(parenthesis?.lawId, dictionary?.lawId);

  return { startIndex, ...(lawId === undefined ? {} : { lawId }) };
};
```

# 条文中の編・章への参照をリンク化する

Issue: #214（#204 から分離）

## 背景

#192 / #202 で条・項への参照をリンク化したが、編・章への参照はリンクにならない。
例: 民法第6条第2項の「第4編（親族）の規定に従い」。

条・項と違い、次の 3 点が新たに要る。

- 編・章の位置表現を解釈するパターンとパーサー
- 着地先となる見出しアンカー（現在、編・章の見出しは DOM 上に id を持たない）
- 章番号は編ごとにリセットするため、「今どの編にいるか」という祖先文脈

## 決定事項

| 論点 | 決定 | 理由 |
| --- | --- | --- |
| 着地先 | ページ内アンカーのみ | #201（項・号の URL 対応）が未着手のため、URL 設計はそちらで一括して扱う |
| 対象表現 | 具体番号 + 相対参照（前編・次編・前章・次章） | 条の previous/next と同じ解法が文書順配列でそのまま使える |
| 節・款・目 | 対象外 | イシューのスコープ外 |
| 現在の編・章への参照 | リンク化する | 見出しは現在位置より上にあり、押せば動く（条の「動かないリンク」抑止とは事情が異なる） |
| 見出し名の差し込み | しない | 「第四編　親族」は番号と名称が一体で、本文側も「第4編（親族）」と名称を伴うため重複する |
| OCR 検出パターン | 変更しない | 「2編」のような裸マッチのノイズが増えるだけで、本件の対象は本文リンク化 |

## 設計

### 1. パターン層 `src/core/jump/reference-pattern.ts`

位置表現の先頭必須トークンに編・章の選択肢を追加する。

```
第<num>編(?:第<num>章)?  |  第<num>章  |  前編 | 次編 | 前章 | 次章
```

「第四編第二章」は 1 スパンとしてマッチさせる。分割すると内部の「編」が
後続「第二章」のガード文字判定（`precedingGuardChars`）に引っかかり、自分自身を誤抑止する。

`buildReferencePositionPatternSource` に編・章を含めるか否かの切り替えを足し、
本文リンク用（`bodyReferencePositionPatternSource`）にだけ載せる。

### 2. 解析層 `src/core/jump/reference-parser.ts`

- `ParsedReference` に `part?: string` / `chapter?: string` を追加。値は `"4"` / `"previous"` / `"next"`。
- `positionStartPattern`（法令名と位置部の境界検出）に `前[編章]`・`次[編章]`・`同[編章]` を追加する。
- `同編` / `同章` / `本編` / `本章` は `同条` と同様に消費のみ（現在位置なのでリンクしない）。
- `hasPosition` の判定に `part` / `chapter` を含める。含めないと「第4編」単独が
  「位置指定なし」と見なされ `undefined` になる。
- スコアは条に準じて加点する（相対参照の基礎点 + 具体番号の加点）。

### 3. 着地先 `src/core/viewer/lawToc.ts`, `src/core/viewer/LawNodeList.tsx`

アンカー id を新設する。

- 編: `pt4`
- 章: `pt4-ch2`（所属編を含める。章番号は編ごとにリセットするため単独では一意にならない）
- 編を持たない法令（日本国憲法など）の章: `ch2`

既存の `a15` / `a15-p2` とは接頭辞が異なるため衝突しない。

`LawNodeBlock` の見出し分岐（default ブロック）で、`Part` / `Chapter` のときだけ
`<section>` に id と `scroll-mt-20` を付ける。附則・別表配下は既存の
`isUrlAddressableArticleContext` で除外される。

### 4. 文脈の伝播 `src/core/viewer/reference-links.ts`, `LawNodeList.tsx`

- `buildHeadingLinkEntries(nodes)` を新設し、文書順の
  `{ partNumber?, chapterNumber?, anchorId }` 配列を作る。
- `ArticleLinkContext` に `headings` と `currentPartNumber` / `currentChapterNumber` を追加。
- `LawNodeBlock` の `position` prop に編・章番号を足し、Part / Chapter ノード通過時に更新する。
- 解決規則
  - 単独の「第2章」 → 現在の編の第2章
  - 「第4編第2章」 → 第4編配下の第2章
  - 前章・次章 → 文書順配列の添字 ±1（編をまたぐ場合も文書順で自然に繋がる）
  - 該当する見出しが無ければリンク化しない

### 5. リンク化の抑止

- `precedingGuardChars` に `編` と `章` を追加する。無いと「国連憲章第7章」が
  自法令の第7章へ誤リンクする（`憲章` は略称辞書に無いため `hasPrecedingLawName` では捕まらない）。
- 編・章の参照は `articleScopeEndIndex`（裸の項参照の抑止）の基準を動かさない。
  条を名指ししていないため、既存の条スコープ判定に干渉させない。

### 6. 型

`ReferenceLinkSegment` の `target` を union にする。

```ts
type ReferenceLinkTarget =
  | { kind: "article"; articleNumber: string; paragraphNumber?: string }
  | { kind: "heading"; anchorId: string };
```

見出しターゲットは常にページ内リンクのため、`onSelectArticle` 経由の SPA 遷移は使わない。
見出し〈…〉の差し込み（`buildCaption`）も条ターゲットのときだけ行う。

## テスト

- `reference-parser.test.ts`: 「第4編」「第2章」「第4編第2章」「前章」「次編」「同章」の解析結果。
- `reference-links.test.ts`
  - 章番号がリセットする複数編の法令で、単独「第2章」が現在の編の章へ解決すること
  - 編を持たない法令で「第2章」が解決すること
  - 「国連憲章第7章」がリンク化されないこと
  - 「第4編の規定……第2項」の混在で、既存の裸の項参照の抑止が壊れないこと
- `LawNodeList.test.tsx`: 編・章見出しにアンカー id が付くこと、本文リンクの href が
  実在する id を指すこと（DOM 契約）。

## 検証

`pnpm run typecheck` / `pnpm run lint` / `pnpm run format:check` / `pnpm test` に加え、
playwright-cli で民法第6条第2項の「第4編（親族）」リンクの実画面とクリック後のスクロールを確認する。
